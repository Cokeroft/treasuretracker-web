# TreasureTracker Web

Frontend website for TreasureTracker — the One Piece Card Game variant guide.

## Project structure

```
treasuretracker-web/
├── index.html       ← main page
├── assets/
│   ├── style.css    ← all styles
│   └── app.js       ← all logic, hits your Railway API
└── README.md
```

## Local preview

Just open `index.html` in your browser — no build step needed.
It will hit your live Railway API automatically.
